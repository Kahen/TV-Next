# TV-Next

Cross-platform media client project for Web, iPhone and iPad, with a shared backend and compatibility layers for user-provided configurations.

> Work in progress. This is a new implementation, **not** a compiled port of the Android application. Supply only sources you are authorized to access. No content sources are bundled.

See `docs/ROADMAP.md` for milestones and `docs/ARCHITECTURE.md` for design decisions once the first implementation is merged.
